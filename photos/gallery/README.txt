Edited photo gallery

1. Add each edited photo to the images folder.
2. Add its title and exact file name to photos.json, keeping the newest photo first.

Example:
[
  { "title": "Lake at sunset", "file": "lake-at-sunset.jpg" },
  { "title": "City lights", "file": "city-lights.jpg" }
]

The same photo file is cropped for the gallery tile and shown larger in the viewer.
Supported web image formats include JPG, PNG, and WebP. Keep file names simple and avoid duplicate names.
